# Folio

**把散落的标签页、收藏和待办，收进同一张桌面。**

每天在各个平台看到有价值的内容，存进收藏夹，然后再不打开。Folio 的逻辑是：看到就存，存了就提醒，提醒了就行动。一个 Chrome 新标签页，解决从"发现"到"完成"的完整链路。

来看看我的 case study：https://foliocase.netlify.app/

---

## 功能说明

### 1. Tab 管理 — 当前标签页总览

打开 Folio（新标签页），左侧主区域展示所有当前打开的标签页，按域名自动聚合分组。

**操作：**
- **查看分组**：同一网站的所有 tab 归为一组，显示标签页数量和标题列表
- **切换到标签页**：点击某个 tab 条目，直接跳转到该标签页
- **关闭标签页**：点击条目右侧的 × 按钮，关闭单个标签页
- **关闭整组**：点击域名组右上角的关闭按钮，批量关闭该域名的所有标签页
- **去重**：点击"关闭重复"按钮，保留每个域名最新的一个标签页，关闭其余重复项

---

### 2. Saved — 一键保存当前页面

在任意网页按下 `Alt+S`，当前页面立即存入 Saved 列表，无需打开插件或操作鼠标。

**操作：**
- **保存**：在任意页面按 `Alt+S`，页面标题和网址自动写入 Saved 列表
- **查看 Saved 列表**：打开新标签页，点击顶部导航 **S**（Saved）或侧边栏进入
- **打开链接**：点击条目标题，在新标签页中打开对应网址
- **删除**：点击条目右侧的 × 按钮，从 Saved 列表中移除
- **拖入 City Map**：将 Saved 中的条目拖拽到 City Map 九宫格中，直接添加为常用网址

> 数据存储在 `chrome.storage.local`，仅限本机。

---

### 3. Pin → Todo 联动

在 Saved 列表中，右键点击任意条目，可将其"固定"到 Todo 任务列表，同时自动创建关联任务。

**操作：**
- **右键菜单**：在 Saved 条目上右键，选择 Pin → Todo
- **查看 Todo**：点击顶部导航 **T**（Todo）进入任务列表
- **标记完成**：点击任务前的复选框，打上完成标记
- **删除任务**：点击任务右侧的 × 按钮
- **跳转原始页面**：点击任务标题，直接打开对应网址

> Pin 数据存储在 `chrome.storage.sync`，多设备登录同一 Chrome 账号时自动同步。

---

### 4. Schedule — 日历任务管理

Schedule 视图提供一个每周日历，可将任务拖拽到具体日期，形成时间维度的工作计划。

**操作：**
- **进入 Schedule**：点击顶部导航 **S**（Schedule）
- **添加任务（侧边栏）**：点击左侧任务列表底部的 `+ task` 按钮，输入任务名后按 Enter 确认，任务同时写入 Todo 列表
- **添加任务（日历格）**：双击日历中任意格子，输入任务名后按 Enter 确认
- **移动任务**：将左侧任务条目拖拽到日历中目标日期的格子上，完成排期
- **删除任务**：点击日历格内任务条目右侧的 × 按钮
- **与 Todo 同步**：Schedule 中添加的任务会自动出现在 Todo 列表；Todo 中完成/删除的任务状态也会在 Schedule 中同步反映

---

### 5. City Map — 常用网址九宫格

City Map 以九宫格卡片布局收藏常用网址，新标签页即是个人工作台，常用工具触手可及。

**操作：**
- **进入 City Map**：点击顶部导航 **C**（City Map）
- **添加网址**：点击空白格子上的 `+` 按钮，输入网址和名称
- **从 Saved 拖入**：将 Saved 列表中的条目直接拖拽到 City Map 空格中，自动填入网址和标题
- **打开链接**：点击已有卡片，在新标签页打开
- **删除卡片**：右键卡片，选择删除；或悬停后点击右上角 ×
- **自定义布局**：拖拽卡片可调整九宫格中的位置顺序

---

### 6. Bookmarks — 文件夹式书签管理

Bookmarks 面板提供层级化的书签管理，支持创建文件夹分类整理链接。

**操作：**
- **创建文件夹**：点击 `+ 文件夹` 按钮，输入名称和 emoji 图标
- **添加链接**：在文件夹中点击 `+ 链接`，输入网址和显示名称
- **重命名链接**：双击链接标题进行编辑
- **删除**：点击文件夹或链接右侧的 × 按钮
- **打开链接**：点击链接标题，在新标签页中打开

---

### 7. Shortcuts — 键盘快捷跳转

Shortcuts 面板允许自定义单字母快捷键，在 Folio 界面内按下字母键直接跳转到目标网址。

**操作：**
- **添加快捷键**：点击 `+ 快捷键` 按钮，依次输入字母键（单个字母/数字）、目标网址、显示名称
- **使用快捷键**：在 Folio 新标签页界面中，直接按下对应字母键，即可在新标签页打开目标网址
- **删除快捷键**：点击条目右侧的 × 按钮
- **保留键说明**：`H`（Home）、`T`（Tabs）、`D`（Deferred）、`S`（Schedule）为系统保留键，不可绑定

---

### 8. 背景主题切换

Folio 支持多套视觉主题，可根据个人喜好切换界面背景。

**操作：**
- **切换主题**：点击界面右上角的主题按钮（调色板图标），从预设主题中选择
- 主题样式包括：默认深色、亮色、暖色等

## 安装方法

> 当前为开发者版本，需手动加载。Chrome Web Store 上架前请按以下步骤安装。

1. 点击右上角 **Code → Download ZIP**，下载并解压到本地文件夹
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 开启右上角 **开发者模式**（Developer mode）
4. 点击 **加载已解压的扩展程序**（Load unpacked）
5. 选择刚才解压的文件夹（包含 `manifest.json` 的那一层）
6. 打开一个新标签页，Folio 即刻启动

**更新方法：** 下载新版本 ZIP 解压后，在 `chrome://extensions/` 页面点击对应扩展的刷新按钮即可。

## 快捷键速查

| 快捷键 | 功能 |
|--------|------|
| `Alt+S` | 保存当前标签页到 Saved 列表（任意页面可用） |
| `H` | 跳转到 Home（在 Folio 界面内） |
| `T` | 跳转到 Tabs 视图 |
| `D` | 跳转到 Deferred（延后处理）列表 |
| `S` | 跳转到 Schedule 日历 |
| 自定义字母键 | 打开绑定的网址（在 Shortcuts 面板中设置） |

## 数据存储说明

| 数据类型 | 存储位置 | 说明 |
|----------|----------|------|
| Pin / Todo | `chrome.storage.sync` | 跨设备同步（需登录同一 Chrome 账号） |
| Saved 列表 | `chrome.storage.local` | 仅本机存储 |
| City Map / Schedule | `chrome.storage.local` | 仅本机存储 |
| Bookmarks / Shortcuts | `chrome.storage.local` | 仅本机存储 |

## 技术实现

| 模块 | 技术 |
|------|------|
| 扩展架构 | Chrome Extension Manifest V3 |
| 全局快捷键 | Chrome Commands API + Service Worker |
| 数据存储 | chrome.storage.sync · chrome.storage.local |
| 后台运行 | Service Worker（持久化监听快捷键事件） |
| 新标签页接管 | chrome_url_overrides |
| 拖拽交互 | HTML5 Drag and Drop API |
| 样式 | 纯 CSS，Space Mono 字体，CSS 变量主题系统 |

## 设计理念

**收藏不是终点，行动才是。**

Folio 不试图替代所有生产力工具，只做一件事：让你在浏览器里看到的东西，真正进入你的工作流，而不是沉入收藏夹再也不见天日。
